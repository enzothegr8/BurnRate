Burn Rate — Type and Space Specification

Fourteen type steps across the three approved roles, a four-pixel space scale, the measure, and the mechanics of the confidence marks at every size. Set in the current system stack, because the pinned faces are metric-compatible and the scale carries over unchanged.

Rev 03 · Navigation moves to mono at the label token, superseding the sans assignment. Article titles take title, in-article H2 takes head, H3 takes subhead. Equidistant spacing values round up. The lockup is exempt from both scales. Rev 02 remains in force: the marks carry no color, line style alone carries confidence, the rule is always jet, and the numeral takes whatever color the context sets.

What the roles already decide for you

The three roles were settled in BR-FOUND Rev 06 and they are more consequential than they look. Mono owns every figure. So the large running statistics on Home are not serif display type with numbers in them. They are mono, at display size, carrying confidence marks. That is unusual, it is a direct consequence of a rule already made, and it is the most distinctive typographic thing about this publication.

The scale

Fourteen steps. Serif is 400 at every size and hierarchy is carried by size alone, never by weight, which keeps the headline voice level with the logo. Sans carries 400 and 600. Mono carries 400, with 600 reserved for labels and tags.

Navigation is mono at the label token, uppercase and letterspaced, muted, with the active item in jet. It is a row of labels rather than a row of words, and setting it in sans would leave it as the only element in the masthead not speaking the system's language.

Headings map by job, not by pixel distance. An article's own title is title. A heading that divides an article body is head. A division inside a section is subhead. Nothing in an article body goes below subhead; if a piece needs a fourth level, the piece is structured wrong.

Mono inside prose

Cascadia sets larger on the body than Selawik at the same nominal size, so a figure dropped into a sentence at 1em looks shouted. The figure token is 0.94em, which lands the digits at the sans x-height. Tabular figures always, so a number does not shift when it updates. Ligatures off, always: a publication about numbers must never render a programming ligature.

The base awards total $1.292B. With the unexercised Blue Origin option the figure becomes $1.573B, and publishing $1.6B without noting the option is unexercised is the exact imprecision this publication exists to correct. NASA's release states the award plainly: $188M base, $280.4M option.

The marks at every size

The notation is the promise, so it has to survive the whole scale. Three bands, and the rule is jet in all three styles. Dotted always carries more weight than solid at the same size, because a dot covers roughly half the length a solid rule does and would otherwise read as the faintest mark in the system. It is a kind, not a degree, and it must not look like a weaker claim.

Color is not part of the mark

The rule is jet in all three styles, exactly as the three segments under the logo are jet. Line style alone carries confidence. The color of the numeral is set by the context it appears in and has nothing to do with how the number came to exist. Every figure below is the same confirmed award, and every one of them is correct.

Two rules follow. A figure never takes blue bright merely for being derived, because blue bright is the link color and a dotted blue figure reads as a hyperlink. And muted grey is no longer the reported color, because grey made reported look like a hedge. Reported is a kind, not a weaker claim, and it is set in whatever color its context calls for like everything else.

Losing the color redundancy raises the bar on the line styles

When the three marks were jet, grey, and blue, color did half the work of telling them apart and line style only had to do the rest. Now line style does all of it. That makes the weight bump on dotted structural rather than cosmetic, and it means any future rendering of a mark, in a chart, in an SVG, in a 3D scene, in an export, has to reproduce the dash and dot geometry faithfully or the notation stops working.

The one place a jet rule cannot go is the jet background used for social cards and video. There the rules invert to white, which BR-LOGO already specifies for the logo segments. Same rule, same reason.

The 12px floor, restated

Blue bright is never used below 12px. This is now a color rule rather than a confidence rule: it constrains any figure set in blue bright for contextual reasons, most often an AI-domain statistic or an AI series in a chart.

label at 11px therefore cannot carry a blue bright figure. Those go up to meta at 12.5px. If a figure will not fit at 12.5px, the layout is wrong, not the rule.

Space

A four-pixel base with ten steps. Every margin, padding, and gap in the system is one of these. The scale is closed in the same way the palette is closed: a new value is a revision to this document, not a decision made inside a component. Equidistant values round up: a value falling exactly between two steps takes the larger, so the same input always produces the same output whoever is doing the mapping.

Measure and columns

The article measure was settled at 64 characters and centered. Everything else is built around it.

Sixty-four characters at seventeen pixels lands near five hundred and fifty pixels of running copy. This is that measure, set in the body token, so the line breaks you see here are the line breaks a reader gets.

Ratified 2026-08-01

Body at 17. Not 18. The register is a record, not a magazine.

Serif at one weight. 400 at every size. Hierarchy is carried by size alone, and the headline voice stays level with the logo.

stat-xl at 64. Large enough to carry the Home hero without a graphic.

Dotted heavier than solid. For visibility. A dot covers roughly half the length a solid rule does.

The marks carry no color. Line style alone. The rule is jet, the numeral is contextual, and the color assignments in BR-FOUND section 4 are superseded.

Navigation is mono at label. Rev 03. The masthead was built in mono and the built version won the argument with the doc.

The lockup is exempt from both scales. Wordmark size, tagline size and line height, tagline tracking, segment widths, and the -0.26em overlap are proportions of one object and belong to BR-LOGO.

Still open after this

Pinning the webfonts. Illustration doctrine. The chart system beyond the color assignments. Motion and 3D doctrine, which does not exist yet and is the next thing to write.

The scale survives pinning. Gelasio is metric-compatible with Georgia and Selawik with Segoe UI, which is why those two were chosen. Cascadia is the exception, so figure at 0.94em is the one value to re-check once the real face is loading.
